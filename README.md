# Peach vs. Nectarine: Interactive Poster

An interactive digital poster comparing peaches and nectarines — origin, nutrition, cooking, and fun facts. School project by Adrian del Valle Miranda, English V.

**Live URL:** https://adrianopai91.github.io/peach-vs-nectarine/

## npm scripts

- `npm run dev` — start dev server
- `npm run build` — production build to `dist/`
- `npm run preview` — preview production build locally
